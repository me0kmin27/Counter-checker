# Counter Checker 사용 방법

현재 애플리케이션은 Python FastAPI로 메일 수신·저장·조회를 제공합니다. OCR 및 카운터 분석은
아직 실행하지 않습니다.

## 1. 실행 및 접속

로컬에서는 저장소 루트에서 다음을 실행합니다.

```bash
make bootstrap
make dev
```

브라우저에서 `http://127.0.0.1:8000`으로 접속합니다. Docker Compose 환경은
`make compose-up`으로 실행하며 `.env`의 `WEB_PORT`로 공개 포트를 변경할 수 있습니다.

## 2. POP 계정 등록

**POP 설정** 화면에서 표시 이름, 서버, 포트, 사용자 이름과 비밀번호를 입력합니다. POP3S는
보통 995, 암호화하지 않는 POP3는 보통 110 포트를 사용하지만 메일 제공자의 실제 설정을
확인해야 합니다. 운영 환경에서는 TLS 사용을 권장합니다.

- **자동 수신 활성화**: Python 애플리케이션의 polling task가 계정을 주기적으로 확인합니다.
- **수신 후 서버에서 삭제**: 수신한 메시지에 POP `DELE`를 수행하므로 초기에는 끄는 편이 안전합니다.
- POP 비밀번호는 `APP_SECRET_KEY`를 이용한 Fernet 암호문으로만 DB에 저장됩니다.

### 수신 필터

계정마다 보낸 사람, 받는 사람(To/Cc), 제목, 본문 키워드, 보낸 날짜(UTC)를 지정할 수 있습니다.
입력하지 않은 항목은 검사하지 않으며 대소문자는 구분하지 않습니다. **모든 조건 만족(AND)**은
입력한 조건을 모두 충족한 메일만 받는 필요조건 방식이고, **하나 이상 만족(OR)**은 입력한 조건
중 하나만 충족해도 받는 충분조건 방식입니다. 필터가 하나도 없으면 모든 메일을 받습니다.

필터에 맞지 않는 메일은 DB에 저장하지 않으며, **수신 후 서버에서 삭제**가 켜져 있어도 삭제하지
않습니다. 따라서 조건을 수정한 뒤 다시 수신할 수 있습니다. 날짜 헤더가 없거나 올바르지 않은 메일은
날짜 조건을 충족하지 않은 것으로 처리합니다.

등록 후 **지금 받기**를 눌러 연결을 확인합니다. 원문 SHA-256이 같은 메일은 계정별로 중복
저장하지 않습니다. 실패 시 표시되는 오류를 바탕으로 주소, 포트, TLS, 인증정보와 방화벽을
확인하십시오.

## 3. 받은 메일 확인

**받은 메일**에서 제목, 발신자, 수신 계정, 첨부 개수와 수신 시각을 확인할 수 있습니다.
상세 화면은 텍스트 본문과 첨부 다운로드를 제공하며, 신뢰할 수 없는 HTML을 직접 렌더링하지
않습니다. 원본은 `.eml` 형식으로 다운로드할 수 있습니다.

## 4. 자동 및 수동 수신

자동 수신 간격은 `POLL_INTERVAL_SECONDS`이며 기본값은 300초, 최솟값은 60초입니다. 별도의
cron 또는 PHP CLI는 사용하지 않습니다. 일회성 수신은 애플리케이션과 같은 환경 변수로 다음
Python 명령을 실행합니다.

```bash
.venv/bin/python scripts/fetch_mail.py
```

Docker Compose에서는 웹 프로세스 자체가 자동 수신을 담당합니다. 로그는 다음으로 확인합니다.

```bash
docker compose logs -f web
```

## 5. 운영 점검

- `.env`와 특히 `APP_SECRET_KEY`를 안전하게 백업하고 저장소에 커밋하지 않습니다.
- MariaDB를 정기 백업하고 `/health` 응답을 감시합니다.
- 외부 공개 시 Nginx 또는 다른 reverse proxy에서 HTTPS를 종료합니다.
- 메일 및 첨부는 현재 DB binary 컬럼에 저장되므로 DB 용량과 보존 정책을 정합니다.
- 설정을 바꾼 후 FastAPI 프로세스 또는 Compose 서비스를 재시작합니다.
